# Reporting rules

1. Never report demo-data metrics as real-world performance.
2. Never claim an assignment is accepted until the portal shows acceptance.
3. Never claim a certificate is earned before the portal qualifies the track and issues it.
4. Keep data source, license/permission, and date in the final report.
5. Follow the exact current FlyRank assignment and capstone briefs over this scaffold.
6. Do not commit API keys, passwords, private datasets, or personal information.
