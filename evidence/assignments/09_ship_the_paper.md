# Ship the Paper — submission checklist

- [ ] The paper follows the official brief and word/format requirements.
- [ ] Every number is reproduced from saved outputs.
- [ ] Dataset provenance and permissions are stated.
- [ ] Evaluation method and split are documented.
- [ ] Baseline and comparison methods are described accurately.
- [ ] Failure analysis is included.
- [ ] Claims match the evidence; limitations are explicit.
- [ ] Code and instructions reproduce the reported results.
- [ ] Links work and no secrets/private data are committed.
- [ ] Submitted through the required FlyRank workflow; receipt/status saved.
