# Tell the story — demo checklist

- [ ] Explain the problem in one sentence.
- [ ] Show the data source and what each row represents.
- [ ] Explain the baseline without jargon.
- [ ] Show metrics and one success case plus one failure case.
- [ ] Explain what the evidence does and does not prove.
- [ ] Show how to reproduce the experiment.
- [ ] Mention limitations and next experiment.
- [ ] Ensure every chart/table is generated from saved outputs.
- [ ] Do not include secrets, private user data, or unauthorized data.
